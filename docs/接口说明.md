# 本地接口说明

服务地址：`http://127.0.0.1:8000`。以下为主要接口，完整字段以各路由代码和响应为准。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /api/health | 本地服务和助手状态 |
| GET | /api/catalog | 产品目录；支持 category、brand、subcategory、q、curated 筛选 |
| GET | /api/catalog/产品ID | 产品、参数和来源详情 |
| POST | /api/profile | 从 text 提取选购需求 |
| POST | /api/recommend | 预算资格筛选、排序和过程说明 |
| POST | /api/compare | 两款产品对比 |
| POST | /api/report | 生成结构化报告 |
| POST | /api/chat | 选购上下文问答和行动建议 |
| GET / POST | /api/assistant/config | 读取公开配置状态 / 保存本机模型设置 |
| POST | /api/assistant/test | 模型连通检查 |
| POST | /api/assistant/transcribe | 可选音频转写 |

需求解析示例：
```json
{"text":"2000元手机，给父母用，希望字体大、操作简单、续航好"}
```

将需求解析返回的 profile 作为推荐请求体。推荐响应区分预算内候选、待核价及超预算状态；请勿仅凭总分判断是否适合买入。

助手请求示例：
```json
{"question":"这款和另一款有什么区别？","profile":{"category":"手机","budget":2000,"scenario":"老人使用"},"product_id":86}
```

产品 ID 随数据版本而异，实际请从目录或推荐返回值选取。报告、对比与助手的完整请求可参照 `frontend/src/api.js`、`advisorContext.js` 与后端测试。

配置与写入接口有本机/来源校验，普通公网部署不能直接照搬本地启动方式。API 密钥不应置于前端代码、浏览器存储或 Git 历史。
