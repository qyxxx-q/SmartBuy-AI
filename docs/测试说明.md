# 测试说明

安装依赖、构建前端后，在项目根目录执行：
```sh
python -m unittest discover -s backend/tests -v
```

后端现有测试覆盖需求解析、预算资格、评分、对比、报价适配、报告、助手上下文、模型与语音接口的边界处理。测试主要使用临时库、合成测试夹具和模拟外部调用，不消耗真实模型额度。

前端：
```sh
cd frontend
npm run build
npm test
```

`npm test` 检查报告阅读组件、助手上下文与导航状态、语音输入状态。页面联调需要先启动 8000 端口的后端，再执行 `npm run test:pages`。

`npm run test:render` 使用 `@napi-rs/canvas` 检查报告绘制和文字边界，生成的图片写入 docs 并由 Git 忽略。Windows 自动尝试微软雅黑；其他系统可通过 `SMARTBUY_FONT` 指定支持中文的字体文件。

`backend/data/*preview.json` 与 `assistant_examples.json` 是历史场景的界面测试夹具，不代表当前在线模型回答或实时行情。

`audit_course.py`、`audit_assistant.py` 包含特定历史数据场景的断言，用于开发诊断；报价随时间过期后不应将这些快照断言当作永远成立的线上结论。`audit_catalog.py` 可检查数据库完整性，并区分原文快照缺失与哈希不一致。

本次整理版的实际验证结果记录于 `验证结果.md`。
