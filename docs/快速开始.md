# 快速开始与开发调试

## 安装与启动

推荐 Python 3.10 及以上、Node.js 20.19+ 或 22.12+，并确认 `python`、`node`、`npm` 可以运行。

Windows 双击根目录 `start-smartbuy.cmd`；也可在 PowerShell 运行 `./Setup-SmartBuy.ps1` 完成安装，再运行 `./Start-SmartBuy.ps1`。若执行策略阻止 `.ps1`，使用 `.cmd` 入口即可。

手动方式见根目录 README。启动 Flask 后打开 http://127.0.0.1:8000。命令行运行时按 Ctrl+C 停止服务。

## 前后端分别开发

终端一，在项目根目录激活 `.venv` 后运行：
```sh
python backend/app.py
```
终端二：
```sh
cd frontend
npm run dev
```
访问 Vite 提示的本地地址；`/api` 请求由 Vite 转发到 8000 端口。修改网页后，正式本地入口需要再次执行 `npm run build`。

## 查看一次完整流程

1. 在“个性推荐”输入预算、品类、使用对象和关注点。
2. 检查提取条件，调整权重，查看预算内候选及推荐依据。
3. 加入两款产品，在“产品对比”查看图表和原始参数来源。
4. 在“智能助手”追问续航、报价或更便宜的候选；配置大模型后可调用模型回答。
5. 到“购买报告”选择产品、对比对象与图片格式，预览并保存 PNG。

历史报价过期时先查看待核价产品与平台查价入口，或运行数据采集更新；不要通过修改采集日期伪装为最新价格。

## 本地数据库

默认生成 `backend/smartbuy.sqlite3`，首次启动从 `backend/data/seed/` 中的可阅读 JSON 记录建立数据库。已有数据库不会被覆盖。需要恢复初始资料时，先停止服务并自行备份数据库，再将运行库改名后重新启动。

公开 GitHub 仓库用于查看和下载代码，网页后端仍需在本机运行。GitHub Pages 无法直接执行 Flask 服务。
