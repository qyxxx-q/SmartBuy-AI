# 配置与常见问题

## 模型服务

推荐通过网站“智能助手 → 模型设置”填写 API 服务地址、模型名称与密钥，测试连接后保存。可用模型名由服务方决定，不要把聊天产品名称直接当作 API 模型名。

本机配置保存在 `backend/data/assistant_settings.json`，已在 `.gitignore` 排除。也可复制 `backend/.env.example` 为 `backend/.env` 设置环境变量；配置优先级以 `assistant.py` 为准。默认不附带任何账户或余额。

未配置时使用本地产品核对逻辑；配置完成不代表每条消息都已调用模型，界面根据实际响应标识使用方式。模型请求失败时可检查服务地址、模型权限、额度和网络，不要将密钥贴到公开仓库。

## 语音功能

浏览器识别依赖浏览器支持及麦克风权限；识别出的文字可修改后再发送。服务端转写需要支持音频转写的服务及单独设置。回答朗读依赖浏览器语音合成。

## 淘宝及其他平台

淘宝适配器支持本机配置 AppKey、AppSecret 和推广位等信息；需要平台实际授予相应接口权限。配置文件或环境变量详见 `taobao_api.py`。京东、淘宝、拼多多、闲鱼的查价链接可用于打开平台搜索，并不意味着四个平台均已完成 API 授权。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 网页显示尚未构建 | 在 frontend 目录运行 npm ci、npm run build，再启动后端 |
| 依赖安装失败 | 检查 Python/Node 版本、网络与包源；不要用旧 Anaconda 环境代替独立虚拟环境 |
| 8000 端口被占用 | 停止之前的本地服务；如修改端口，同时修改 Vite 代理 |
| 没有预算内推荐 | 检查品类、预算、报价时间、配置和资格；历史报价会过期，可查看待核价候选和平台查价入口 |
| 模型服务拒绝请求 | 核对服务地址、模型名、密钥、权限和额度；查看本机错误提示 |
| 数据库损坏或要恢复 | 停止服务、备份运行库，改名后重启，从种子库恢复 |
| 更改网页但页面没更新 | 重新构建 frontend/dist，或使用 Vite 开发入口 |

公开资料包没有用户设置、会话记录、浏览行为、密钥和个人论文/PPT。添加自己的配置后仍应保持这些文件未被 Git 跟踪。
